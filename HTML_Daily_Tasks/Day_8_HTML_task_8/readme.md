# Day 8 - HTML Task 8 🎧

## 📌 Project Title
**Music Mood Selector**

## 📖 About the Project

This project is a beginner-friendly HTML webpage created as part of my **HTML Daily Tasks**.

The webpage is designed around a **Music Mood Selector**, where users can choose their current mood and explore a simple playlist based on different moods.

It also includes a small form where users can enter a song name, artist name, and mood to create their own playlist entry.

## ✨ Features

- 🎧 Music mood selection
- 😊 Different mood options
- 🎵 Playlist table
- ⭐ Current mood section
- 📻 Create your own playlist form
- 📝 Song name and artist input
- 🔽 Mood selection dropdown
- 🎨 Emoji-based user interface
- 📱 Basic responsive HTML structure
